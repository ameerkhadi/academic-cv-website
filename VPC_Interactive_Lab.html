1.3 · CIDR NOTATION
Classless Inter-Domain Routing
CIDR
A method to express a range of IP addresses. Format: IP/prefix.Example: 10.0.0.0/24 = 256 IPs from 10.0.0.0 to 10.0.0.255
 notation uses a slash + number to indicate how many bits are fixed (network) vs flexible (host). Use the calculator below to explore.

2.1 · VPC FUNDAMENTALS
What is Amazon VPC?
Amazon VPC
Virtual Private Cloud — a logically isolated section of AWS where you run resources.Example: Create VPC 10.0.0.0/16 in us-east-1. Launch EC2 and RDS inside it. Other AWS customers cannot see or access it.
 lets you provision a logically isolated network. You control the IP range, subnets, routes, and gateways.
🔒
Logically Isolated
Your VPC is completely separated from other AWS customers. Traffic cannot cross between VPCs unless you explicitly allow it via VPC Peering or Transit Gateway.
Example: Bank A and Bank B both use AWS — completely separate networks
🌍
Regional + Multi-AZ
A VPC belongs to one Region. Subnets within it can span different Availability Zones for high availability.
Example: VPC in us-east-1 with subnets in us-east-1a, 1b, and 1c
📋
CIDR Block Required
When you create a VPC, assign an IPv4 CIDR block. Cannot change after creation!
⚠️ Range: /16 (65,536 IPs) max · /28 (16 IPs) min
🗺
Public vs Private Subnets
Public subnets have internet access via Internet Gateway. Private subnets have no direct internet access (use NAT for outbound only).
Example: Web servers in public, databases in private

2.3 · ROUTE TABLES
Route Tables & Routes
A route table
Rules that tell the subnet where to send traffic. Each route = Destination CIDR + Target.Route: 0.0.0.0/0 → igw-id means: send all internet traffic to the Internet Gateway
 contains routes with a Destination CIDR and a Target. Every subnet must have one route table. The local route (VPC CIDR → local) is permanent and cannot be deleted.

3.1 · INTERNET GATEWAY
Internet Gateway (IGW)
An Internet Gateway
A scalable, highly available VPC component. Attached to your VPC — allows public subnets to communicate bidirectionally with the internet.Without an IGW, no traffic can enter or leave your VPC from the internet
 allows communication between instances in your VPC and the internet. It performs NAT for instances with public IPs. You must: (1) attach it to the VPC, and (2) add a route 0.0.0.0/0 → igw-id.

3.2 · NAT GATEWAY
Network Address Translation Gateway
A NAT Gateway
Allows private subnet instances to INITIATE outbound internet connections (e.g., for updates) while blocking all inbound connections from the internet.Example: RDS database downloads MySQL patches via NAT — but internet users cannot connect to the DB
 sits in a PUBLIC subnet with an Elastic IP, allowing private instances outbound internet access only.

✅ NAT Gateway (Recommended)

Fully managed by AWS — zero admin
Auto-scales up to 100 Gbps
High availability within one AZ
Must be in PUBLIC subnet + Elastic IP
One per AZ for full HA
Cost: Per-hour charge + data transfer. Release when not needed!

⚙️ NAT Instance (Legacy)

Self-managed EC2 instance
Manual scaling needed
Must disable source/dest check
Can act as bastion host
Higher admin effort
⚠️ AWS recommends NAT Gateway for all new deployments

🔑 Sections 1–3 Key Takeaways

  • IPv4 addresses are 32 bits (4 octets). CIDR /n means first n bits are network, rest are host
  • A VPC belongs to one Region, can span multiple AZs. CIDR cannot change after creation
  • AWS reserves 5 IPs per subnet: .0 network, .1 router, .2 DNS, .3 future, .255 broadcast
  • Route tables: local route is permanent. Add 0.0.0.0/0 → igw-id for public internet access
  • Internet Gateway = bidirectional internet access for public subnets
  • NAT Gateway = outbound-only internet from private subnets. Lives in public subnet + needs Elastic IP
