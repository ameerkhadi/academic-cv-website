# محاضرة الذكاء الاصطناعي بإدارة العمل

هذا مجلد HTML مستقل لعرض المحاضرة العربية كشرائح. لا يحتاج إلى React أو Node.js أو قاعدة بيانات؛ يكفي رفعه إلى GitHub وتفعيل GitHub Pages.

## الرفع إلى GitHub

أنشئ مستودعاً جديداً على GitHub، ثم ارفع `index.html` ومجلد `assets` كاملاً. من إعدادات المستودع افتح **Pages**، اختر **Deploy from a branch**، ثم اختر الفرع `main` والمجلد `/root` واضغط **Save**. بعد دقائق سيظهر رابط الموقع.

## الاستخدام

يفتح الموقع الشريحة الأولى تلقائياً. استخدم أزرار **التالي** و**السابق**، أو سهمي لوحة المفاتيح. مفتاح المسافة يشغّل ويوقف العرض التلقائي، ويدعم الموقع الهاتف والكمبيوتر واتجاه العربية من اليمين إلى اليسار.

## ملاحظة مهمة

لا تغيّر أسماء الصور داخل مجلد `assets` إلا إذا عدّلت أسماءها أيضاً داخل مصفوفة `slides` في نهاية ملف `index.html`.
