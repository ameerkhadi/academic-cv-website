# ليلة الاختراق · Cloud Breach Night

محاضرة تفاعلية كاملة لمادة **Cloud Computing Security** (جامعة الشعب، قسم هندسة الأمن السيبراني، المرحلة الرابعة)، تغطي محورين من المفردات:

- **حوكمة السحابة والمخاطر والامتثال والجوانب القانونية:** تقييم مخاطر السحابة، و CSA CCM و STAR، و ISO/IEC 27001 و 27017 و 27018، و SOC 2، والعقود واتفاقيات مستوى الخدمة، وسيادة البيانات، و PDPA الماليزي وقانون الأمن السيبراني الماليزي ٢٠٢٤ و GDPR.
- **Cloud IAM I:** المستخدمون والمجموعات والأدوار والسياسات، وأقلّ صلاحية، ومنطق تقييم السياسات، وبيانات الاعتماد المؤقتة، و MFA.

المحاضرة مبنية حول محاكاة اختراق سحابيّ ثلاثية الأبعاد من ستّ مراحل على نمط حادثة Capital One سنة ٢٠١٩، يلعبها الصف في فريقين.

## التشغيل

ملف واحد: `index.html`، ومعه نسخة محلية من مكتبة three.js في `vendor/` حتى تعمل المحاكاة دون الاعتماد على شبكة توزيع خارجية. يُفتح من أيّ استضافة ثابتة (مثل GitHub Pages) أو محلياً عبر:

```bash
python3 -m http.server 8000
# ثم http://localhost:8000
```

## المحتوى

هذه الصفحة تحتوي **المحاكاة وحدها**، وفيها زرّ للعودة إلى الأسبوع الثالث.

أمّا الشرح، والمصطلحات، ومدخل IAM، وشرح المراحل الستّ، والأسئلة مع الحلول، فقد نُقلت إلى الأسبوع الثالث في دفتر المادّة (`cloudsec/week1.html#week3`)، ولم يُنقل منها ما كان مكرّرًا.
